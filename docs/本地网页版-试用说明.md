# Yorevia 本地网页版 · 试用说明

这是源代码和已构建网页，不是网站，也不是 macOS 安装包。数据库、索引和原件都由运行服务的电脑处理，地址固定为 `http://127.0.0.1:4173`，只供那台电脑访问。

Linux 桌面上按 [安装说明](LOCAL-WEB.md) 一次性配置 Python 环境和入口后，从应用菜单点「Yorevia Web」就能打开浏览器，日常不用终端。第一次在系统窗口选库，之后重启服务可重新打开同一库。可选登录后在后台启动。桌面版和网页版不要同时打开同一个库。

百度网盘递归扫描选中目录中的照片，只读取列表；浏览时间轴和详情时按需读不同大小的预览，不批量下载原图。网页版暂不保留百度登录，也不会搬动桌面版钥匙串里的授权。

云端用合成资料验证了递归索引、图片 API、故事保存和进程重启；百度路径使用模拟提供方。真实百度和 macOS 上的浏览器、原生选目录以及启动器仍需验收。
