# 从工程预览到可用 Alpha：验收清单

## 已有代码，需持续验证

- 本地目录扫描、SHA-256 去重、原件只读、日期来源、缩略图、时间轴分页。
- 人像模型适配和保守归类；人名、合并/拆分；年度同框图谱、人工关系时间范围。
- 原文故事和资料引用，Markdown/JSON/HTML 导出。
- Tauri macOS / Windows 外壳、原生目录授权、私有 Python sidecar。
- 双系统三架构的 GitHub Actions 打包定义。

## 发布阻断项

1. **真实模型可用性**：执行固定哈希模型加载与推理；使用得到授权的多年份照片集，人工标注身份，测量误合并/漏合并，而不是仅报告“有检测到脸”。不提交测试人脸或嵌入到公开仓库。
2. **三目标构建**：macOS ARM64、macOS x64、Windows x64 工作流全部成功；明确每个包的实际校验值和依赖锁。
3. **真机流程**：首次安装→目录授权→导入→关闭/重开→人物确认→故事→备份/导出；检查中文/空格路径、外接磁盘、只读目录、复制中断、恢复和卸载。
4. **性能**：以授权的 1 千 / 1 万 / 10 万资料集测吞吐、峰值内存和重扫速度。当前遍历先收集路径到内存；尚无大规模性能承诺。
5. **稳定性**：大/损坏媒体的解码隔离与超时、进程崩溃恢复、模型错误重试、数据迁移与备份恢复测试。当前原生解码库有崩溃/长时间阻塞的可能，不能把线程取消视为所有解码操作可立即终止。
6. **发行安全**：Apple 签名/公证、Windows 签名、软件物料清单、第三方许可证与原生编解码器核验；必要时安全审计。

## 下一轮功能，而不是已完成的承诺

- 可恢复的资料库备份/导入、在线备份 API，人物合并撤销和修正历史。
- 可信的一键跨来源重新定位；源删除/断开向导与隐私清理策略。
- 近似日期和人生阶段、独立事件、地图、关系多层视图。
- 视频拍摄时间解析、视频片段引用、人像检测；按需后台扫描和文件监听。
- 跨年龄/低质照片更好的模型，质量评估与增量聚类重算。
- 更完整的传记排版/EPUB、可选本地 AI；必须保留原始叙述和证据来源。
- 加密资料库、用户自主同步、移动端只读浏览；不把社交发现或云存储作为前置条件。

**产品验收原则：** 不写一句故事，也能从已有资料获得价值；但不把算法的缺失或猜测改写成一个人的人生事实。
