# 百度网盘来源（开发者预览）

## 实现范围

在「添加来源」或「资料与隐私」中选择百度网盘。当前版本使用 **开发者自行取得的用户 Access Token**，不是 AppKey、SecretKey 或 SignKey；不是面向普通用户的一键登录发行版。

1. 先打开本地资料库，再连接百度网盘。
2. 在应用内输入你通过百度官方授权流程取得的 Access Token。不要发送到聊天、issue 或公开文档。
3. 浏览目录，每页最多 100 项；只勾选本页文件。文件夹用于导航，不会递归扫描整个网盘。
4. 选择资料库外的本地保存位置。新建 `Yorevia-Baidu-<随机ID>` 专用目录，下载选中文件，再调用原有本地索引。
5. 单文件最多 1 GiB、单次最多 2 GiB。支持现有照片、视频、TXT/Markdown 类型。
6. 断开连接、切换资料库或退出会丢弃此进程持有的授权。令牌过期后需重新授权，当前不自动刷新。

取消会清理未完成下载，保留已下载文件。若取消或失败发生在索引之前，在「资料与隐私」的该来源上增量扫描，可索引已完成文件。此版本不自动重试、不自动去重下载、不支持断点续传；内容索引仍按 SHA-256 去重。文件删除、上传、分享、远端同步均未实现。

## 凭据与隐私

源码和安装包 **不包含应用 SecretKey/SignKey**，不要求普通用户共用开发者的用户令牌。Access Token 仅在前端提交时短暂存在，并由本地 Python 引擎保留在内存；不写入 SQLite、配置、日志或导出。输入框为密码字段；这里不承诺对进程内存进行密码学擦除，也不防止已控制电脑的攻击者读取内存。

用户主动启用该来源后，引擎会直接访问百度 API/下载域名；原始文件下载到本机，不经 Yorevia 服务器。文件名、路径等请求由百度服务处理，本地媒体分析仍在设备上。原有“不联网”说法只适用于不启用网盘的本地整理流程。

HTTP 与 API 错误经过归一化，不回显携带令牌的 URL 或上游错误文本。下载地址与重定向只允许 HTTPS 百度域名；原始名字不会成为磁盘路径，专用新目录防止覆盖已有文件。桌面端下载位置必须由系统目录选择器授权。下载目录仍是未加密的用户文件，用户需自行管理备份和删除。

## 公开分发路线

公开 GitHub 源码、无密钥的安装包没有冲突。不能把应用 SecretKey 编译进桌面客户端，也不能通过 CI Secret 注入后误以为安装包安全。

普通用户流程需要：安装 Yorevia → 点击百度网盘 → 百度官方登录授权 → 选择文件。百度官方 SDK 的授权码兑换、设备码兑换及刷新令牌均需要应用 SecretKey；因此建议另行部署最小 OAuth 授权服务，在服务端密钥存储中保管应用秘密。服务不接收照片和视频；每个用户独立授权，注意 state/PKCE 可用性核实、一次性票据、回调绑定、令牌保管、撤销、限流与日志脱敏。客户端持久授权应使用 macOS Keychain / Windows Credential Manager，不写资料库。

**设备码授权服务和桌面客户端已有未部署的原型，尚未进行真实授权验证**。详见 [服务说明](../services/baidu-oauth/README.md)。须先验证应用审核状态、读取/下载权限、配额、可用授权流程、回调地址，以及隐私政策与服务运营安排，再开放公众使用。不能保证创建应用后已自动获得公众可用权限。

## OAuth 原型（2026-11-17，默认关闭）

现在另有无需手工复制 Access Token 的设备授权原型：原生进程配置 `YOREVIA_BAIDU_OAUTH_URL` 为运营方的 HTTPS 根地址后，连接窗口会出现「使用百度账号授权（测试版）」。点击后系统浏览器打开百度官方设备授权页，用户输入应用显示的一次性验证码并同意授权，桌面端自动完成连接。没有配置服务时不显示此入口，不假装可以登录。

服务源码位于 `services/baidu-oauth/`，与桌面安装包隔离。它以服务端环境秘密保存应用凭证，创建最多 10 分钟的会话，随机客户端 proof 绑定轮询，令牌只交付一次。无需自定义 URI 或本地回调端口。首次版本不保存或刷新长期授权，退出后需重新登录。关闭窗口或切换资料库取消待完成授权，服务重启也会使会话失效。

本次没有创建服务器、站点或外部账户，没有部署、费用或配置真实密钥。现有安装包不包含这些未发布的新更改。必须先完成独立审查、服务端秘密安全输入、HTTPS/代理日志脱敏、限流与百度实际权限验收；普通用户不需要申请自己的应用或持有开发者秘密。设备码是官方 SDK 支持的流程，但这个应用是否获准使用仍待真实环境验证。

原型验证：27 项 Node 测试（18 服务端、9 前端）和 27 项百度相关 Python 测试通过；独立审查发现的 HTTP 400 授权等待兼容及错误配置破坏离线启动问题已修复并复核。Mac 完整 Python 套件为 71 通过、1 跳过（未装模型）、1 失败：既有 `test_loopback_preview_boundary` 对伪 Host 预期 403，当前执行环境实际返回 502，尚未确认为产品缺陷或环境拦截。此轮未重新打原生安装包、未进行真实百度账号端到端验证。旧安装包验收不能代替本轮验证。

后续定位：同一预览进程中，urllib 伪 Host 请求经本机执行环境返回 502，而直接 loopback socket 与 `http.client` 均返回应用的 403。将该单条安全测试改为 `http.client` 直连本地监听器后，全套 Python 为 **72 通过、1 跳过**（真实模型未安装）；Node 27 项及 TypeScript 检查/构建通过。未改变产品 Host 校验或系统网络设置。
